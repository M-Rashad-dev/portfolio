## ⚡ Concept: The Request Lifecycle

A high-performance portfolio representing the journey of an HTTP request through a modern full-stack web application:
- **Client (React.js):** Interactive client-side interfaces and responsive design.
- **Middleware & Kernel (Laravel):** Multi-authentication, role guards, and request validation.
- **Controller & Service Layer:** Clean Architecture, Domain-Driven Design & Multi-Tenancy.
- **Cache & Data Layer:** Redis caching and Eloquent ORM.
- **Response:** Optimized 200 OK payloads with high Google Lighthouse performance scores (97%+).

---

## 🛠️ Tech Stack

- **Core:** React 19, Vite
- **Styling:** Tailwind CSS 3.4, PostCSS, Custom CSS Variables
- **Animations & Motion:** Framer Motion, GSAP (ScrollTrigger), Lenis Smooth Scroll
- **Localization:** i18next & react-i18next (Arabic RTL default, English LTR toggle)
- **Icons:** Lucide React, Simple Icons, FontAwesome 6

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/M-Rashad-dev/portfolio.git

# Navigate to project directory
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```
